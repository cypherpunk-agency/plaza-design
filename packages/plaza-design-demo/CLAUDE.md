# Plaza Design Demo

Two outputs share this package: the React design-system showcase (`src/components/`, `dist/`)
and the static cypherpunk.agency homepage with ACCESS DENIED (`src/ssg/`, `dist-homepage/`).

## Purpose

Research, develop, and fine-tune the design approach.
The game and design system are both in active design; existing documents are revisable.

## Game work

Read `src/ssg/game/README.md` and `src/ssg/game/CLAUDE.md` for the code map, commands and
documentation roles. `pnpm dev` serves the React showcase, not the game.

## Guidelines

- Follow design-guide principles
- Check plaza-design-guide/CLAUDE.md before design changes
- Treat differences between implementation and a guide as something to investigate, not an
  automatic reason to stop. Follow the user's current direction; ask only when a material
  design choice remains ambiguous.
