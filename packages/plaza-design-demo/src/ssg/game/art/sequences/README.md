# Animated artwork and authoring

`opening/sequence.ts` and `cinematics.ts` are shared dispatchers for shipping playback and the composer. Source documents live under `story/title/` and `story/cutscenes/`. Trusted motion kernels preserve the original formulas; JSON controls sequences, composition, shots, tracks, cards, fades and named handoffs. Preview seeking uses an isolated `IntroSeekSession`; it does not apply gameplay handoffs.

The opening currently has 179 registered drawing pieces, including nested coast/town groups. Individual pieces expose meaningful typed appearance fields, with exact original defaults materialized in the composition document. Palms, loungers, the DJ booth, bonfire, stacks, cranes, port vehicles, people, towers/signs and lamps consume these fields in their existing drawing kernels. Cinematics have 28 pieces; nine expose appearance/text fields. Duplicated furniture, vehicles and cinematic parts receive their own properties.

Coast `worldX` follows the original west-facing coast coordinate system. Generic instance placement is an offset applied after the native layout. Point/viewport culling accounts for moved, scaled and flipped instances; changed appearance uses an uncropped native pass so enlarged or relocated artwork cannot disappear behind its original culling envelope. The real canvas clips the result.

`opening/metadata.ts` and `cinematic-metadata.ts` supply the same bounds and anchors to registry and preview. Common-kit furniture/plants/cranes and named coast assemblies measure their actual canvas operations through `opening/measure.ts`. Text, curves, glows and several procedural backgrounds use conservative extents, not raster-tight selection. SALT now has ten independently selectable bar, sign, counter, stool and lighting pieces; the pier has thirteen deck, kiosk, bench and lighting pieces; the buffer has eight fence, sign, surveillance, lighting, car and gate pieces. Each sits inside an assembly group with inherited placement and visibility. Hub, ship, bridge and Galleria internals remain the next extraction batch. A finite bounds contract does not establish full G4 addressability.

Focused checks: `check-sequence-commands.mts` compares original/native/composed effective paint commands, state and transforms at boundaries (independent scopes are permitted); `check-sequence-documents.mts` validates source documents and deterministic packet replay; `check-sequence-editing.mts` exercises appearance, duplicate isolation, relocation/culling and geometry. Browser pixel comparison against the immutable baseline remains the acceptance gate after each batch.
