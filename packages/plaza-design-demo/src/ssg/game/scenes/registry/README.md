# Registry service point (Act I)

Act I Chapter 1, beat 5 (docs/design/ACT-I-REDESIGN.md). Built from the `dt-registry` art set.
Open only in office hours: the `office-hours` barrier carries a 08:00 to 18:00 time condition, so
the player waits rather than the clock being pinned. Ticket, queue, "Please hold", Ines Varga and
an appointment in 90 days: a ticket plus meeting Ines sets `act1:queued`. The staff door stays shut until
Chapter 4.
