# Corner Shop composition

`composition.json` is the editable source for 49 instances. The scene adapter derives the shop width, spawn, exit, buying position, readable positions and resident placement from it. Counter accessories and the keeper attach to the counter; window glass and outside residents attach to the back window; the cat attaches to the fridge top.

`shop-elements.ts` registers the individual native drawing kernels. The factory receives prepared actors and a lighting snapshot; it does not read the current clock, light state, saves or scene rules. Eight upper rooms preserve their generated boxes/windows/bulbs as room assemblies. Shelf stock, equipment dimensions, upstairs room size and sign text have typed controls. Remaining room internals and decorative sign content can be decomposed further without changing the composition contract.

Runtime and composer use `shopEnvironment` plus `drawShopComposition` / `drawShopForeground`. Preview controllers supply the same actor map and environment snapshots and can override visibility, opacity, animation clips and time. `shopArt` aliases the shared central catalogue, including additions such as furniture stools. `shopScene(document, state, options)` creates shipping and edited preview scenes through the same renderer. It copies actor templates for each scene; editor creation does not mutate canonical actors. `shopFrameEnvironment` exposes the equivalent source-aware bindings.
