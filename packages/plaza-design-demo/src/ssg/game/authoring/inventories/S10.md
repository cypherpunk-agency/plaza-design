# S10 frozen vehicle viewing scope

The executable inventory is `S10.ts`: 35 named families, renderer/source references, supported
controls, native-versus-placement routes and explicit restrictions. `VEHICLE_MATRIX` freezes
default, animated and reduced-motion rows for every family plus one row per supported control.
It is a bounded state matrix, not exhaustive combinations. The ground machinery preview also
exposes normalized lift/reach as supported pose controls; these do not advance machinery rules.

All previews use shipping render functions. Ground/craft placement routes are stationary or a
deterministic linear inspection transform; speed moves that transform in world units/second.
They are clearly distinguished from native embedded Harbor, fleet and opening routes. Native
route formulas remain in their real renderer; unsupported speed/facing/payload states are disabled.
Rail doors and passengers use explicit snapshots, never the mutable transport singleton.
Metro passenger variation is seeded, not an invented empty train. The canal preview retains its
vault, water and prepared occupant. Harbor forklift is a frozen presentation pose, not a shuttle
simulation. Opening ships/boats retain the actual piece dispatch and visibility rules.

Operations: select, deterministic play/pause/step/seek/loop/reduced motion; zoom/pan/reset camera.
Preview state is temporary, has no Save action, and does not change source or player storage.
Runtime equivalence must retain numeric command/pixel comparisons for the frozen matrix and
isolation checks around transport, city clock, weather/light, storage and source snapshots.
F3 passed the frozen 229-case matrix, 102 visible supported-control effects, 64 native machinery containment cases, independent decoding of 687 PNGs and actual mounted UI operations. See `S10-acceptance.json` for evidence and source pins.

Visibility corrections retain native camera semantics (`wx - camera × parallax`). Every default
must contain artwork; every supported-control probe must change visible pixels with both sides
visible. The straddle preview fits its complete elevated cab. Delivery drone facing is unavailable
because its native renderer exposes no facing and its hull is symmetric. Long inspection routes
also have separately labelled culling rows; these are not used as evidence of a visible control effect.
