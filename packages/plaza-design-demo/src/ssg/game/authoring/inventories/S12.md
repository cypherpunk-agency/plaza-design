# S12 read-only event inspector

The frozen scope is S12.inventory.json; S12.evidence.json records the focused check.
Final F5 acceptance and root-observed browser results are pinned in S12.acceptance.json. Run it from
packages/plaza-design-demo with `pnpm exec tsx scripts/scene-system/check-event-inspector.mts`.

## Integration

Import `mountEventInspector` from `authoring/event-inspector.ts`. Pass the current immutable
`documents` array, optional `initialScene`, and navigation callbacks:

```
const dispose = mountEventInspector(host, {
  documents,
  initialScene: 'sandbox',
  onOpenScene(scene, instanceId) { /* select the existing scene/object */ },
  onOpenSource(source) { /* show source.file, source.pointer or source.symbol */ },
});
```

Call dispose when replacing the panel; remount when authoring documents change. No service,
write API or game save is used. Source paths are relative to `src/ssg/game`. JSON pointers resolve
to actual definitions. Code symbols link the registered controller entry point or implementation
module; callback bodies are not converted into invented graphs. For callbacks imported by a
SceneDef, index.ts is the source entry point rather than a claim about the final definition line.

`buildEventInspection` is usable without the DOM. It reads actual SCENES/data/net/logic and
registered factory contract shapes, plus supplied compositions and timelines. It does not
instantiate a rule factory or a SceneModel. Generated SEAL/WATCH noun declarations follow the
engine's sector/route construction; unbounded player-created module ids remain outside the
finite inventory. Connections distinguish containment, triggers, condition dependencies,
actions, signals, networks, travel, attachments and sequence handoffs. No active inference is
made from source defaults. Edges without captured runtime state are unbound.

Optional snapshots accept only explicit `origin: 'captured-runtime'` records. Condition records
must exactly match scene/device/noun/expression; false is blocked, true active. This reports the
predicate result, not proof that an ordered case was chosen. A capture without matching context
stays unbound. Node-state captures can mark declared nodes active/inactive/blocked; missing or
opaque nodes cannot be made valid by a state capture. Captures must be prepared by a trusted
external probe; the inspector never evaluates expressions, calls snapshot/restore, executes
callbacks or reads player storage. Runtime expression scope/precedence stays engine-owned.

The UI exposes scene, node kind, status, connection kind and text filters, incoming/outgoing
linked neighbors, source metadata, declared data, and source scene/object navigation. Opaque
rules/effects/panels/uses stay visibly opaque. Missing targets remain distinct from unavailable
condition evaluations. Inspection does not run effects, traverse routes or advance clocks.
Browser integration and navigation are verified separately from the focused model check.
