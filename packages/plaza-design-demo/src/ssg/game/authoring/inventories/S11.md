# S11 frozen viewing scope

`S11.ts` freezes 33 typed kernel families (including all 15 screen/sign renderers plus camera,
both LINE0 signs, four legacy primitives, the seeded tower and ten architectural kernels).
The tower variant list records every existing skin/crown/gear/sign kind. Every supported variant,
night/alternate text or supported-power state, and reduced-motion state has an executable row.

`S11.embedded.json` freezes exact registered ids and source placement references from S8.
Each type is offered with every frozen source usage; tests select one actual usage per type,
preferring a native scene, plus day/night/rain composed-frame rows for every represented scene.
No fabricated schema is used for shared definitions. Sequence usage needs the actual supplied
sequence renderer; without that provider the UI reports it unavailable and offers Open instance.

Typed standalone previews use the real exported art kernels. Their explicit snapshot includes
time, seed, Light, variant, mounting, text and only supported brightness/power inputs. They do
not pretend to carry scene-wide illumination or weather. Embedded source mode renders the whole
native scene/sequence, preserving siblings, order, shadows, grading and environment responses;
isolated mode reuses the existing prepared artwork adapter and states its missing frame passes.

Operations are family/variant/source-usage selection, temporary text and supported brightness,
day/night, native weather for composed scenes, camera/zoom, play/pause/step/seek/loop/reduced motion,
and Open instance. Unsupported combinations are visibly disabled. No source Save, world mutation,
rules, transport/schedule stepping or graphic redesign is part of S11. F4 is accepted against `S11-acceptance.json`: the frozen kernel and embedded matrix,
real controls, determinism and isolation evidence all pass.

`S11.states.json` freezes three existing source light controls before exposing them: Beach
`lamps` = on/off, Sandbox `lampOn` = false/true, and Sandbox `nightLight` = false/true within
its real night window. These pass through the native preview's validated local model snapshot;
the shared scene frame decides both visible artwork and illumination. No verb, quest, schedule
or player state is executed. Other model fields, including billing, are outside S11.

Native support audit: Billboard screens force wall mounting. `Gear` declares `billboard`, but
the native roof-gear renderer has no such branch; that option is retained as explicitly unavailable,
while the implemented `sign:billboard` remains selectable. Panel previews do not force concrete
balconies on, so its native balcony bands remain distinct. Clear-band inspection covers actual
pipe/steam depths60–140. Broken-screen ghost text is inspected during its native on pulse at0s;
it is expected to disappear between pulses. Flat crown and the default concrete flat tower are
explicitly equivalent native defaults, not falsely claimed to produce different artwork.


Final acceptance covers all 776 ordered cases with zero native and repeat differences,
115 supported-control effects and six focus/pan/scale probes. All 2,328 image references
are independently decoded and compared as RGBA by Pillow. The `S11-final-reset` reports
pin the final fixture bundle and 268 actual source inputs. Reused images are referenced
only after bytewise comparison with final actual captures; changed frames have fresh
source/candidate/diff images. Browser raster evidence uses an explicit global readback
context policy, recorded and asserted for every observed 2D canvas. Earlier backend and
editor snapshot failures remain retained as diagnostics. The integrated mounted screen
passes its 11 required operation checks plus native environment-pixel changes, including
animation disposal, exact source-instance navigation and source/player-storage isolation.
