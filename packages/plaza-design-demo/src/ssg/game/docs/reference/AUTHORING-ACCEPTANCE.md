   actor graphs, deleting the intended graph could silently select somebody else's conversation.
   All six shipped native talk actions now carry explicit graph IDs; validation rejects absent
   bindings and the Model and panel fallbacks are removed. Native target action controls also bind an explicit
   graph atomically; Events inspection follows that same reference. Current metadata check compares their targets
   against immutable pre-change source b629f31 and executes actual native dispatch. No text,
   rewards, permissions or intended graph target changed.
2. Inspector lookup ignored manifest-bound devices and string targets. It now resolves both
   source representations, deduplicates legacy bindings and exposes every device on an object.
   Browser app-F5XVVSC4.js: create review-bound, bind it to Library's reference-book, select the
   book, open Device/Wiring, verify the new device, Undo binding and creation; no alerts or edits
   remain. The later fixed-cable checkbox does not change this lookup.
3. Fixed cables previously hid author controls. The typed author editor now exposes the same
   endpoints/verb/removal plus the player policy. Native cut protection is unchanged by default.
